# 树莓派健康监护系统 · 接线总表

**项目**：raspberry-health-monitor（树莓派居家老人健康与安全监护系统）
**平台**：Raspberry Pi 5 Model B Rev 1.1 ／ Debian 13 (trixie) ／ Python 3.13.5
**生成日期**：2026-09-24
**依据**：`rpi/config/devices.json` 与 `rpi/health_monitor/hal/pins.py`（**引脚号从代码读取，非手写**）
**校验**：`python3 scripts/validate.py` 第 5 项「引脚冲突」通过（7 个独占引脚无冲突）

## 0. 三分钟总览

| 总线 | 器件 | 地址／片选 | 关键物理脚 |
| --- | --- | --- | --- |
| I2C1 | MAX30102 心率血氧 | 0x57 | 3(SDA) / 5(SCL) |
| I2C1 | LCD1602 液晶 | 0x27 或 0x3F（自动探测） | 3(SDA) / 5(SCL) |
| 单总线 | DHT11 温湿度 | — | 7 (GPIO4) |
| GPIO | HC-SR501 人体红外 | — | VCC=2(5V) / OUT=11(GPIO17) / GND=6 |
| SPI0 | TFT 彩屏（ST7735S） | CE1 = 脚26 | 19/23/26 |
| SPI0 | TFT 彩屏 1.8 寸 | CE1 = 脚26 | 19/23/26/18/22 |
| GPIO | 蜂鸣器 | — | 12 (GPIO18) |
| GPIO | LED 绿／黄／红 | — | 15 / 16 / 18 |
| GPIO | 求救按键 | — | 13 (GPIO27) |
| GPIO | （拓展）HC-SR04 超声波 | — | 29 / 31 + 电平转换 |

> 供电原则（**照这个接，别照别的**）：
> **3.3V（脚 1/17）**：MAX30102、DHT11、TFT
> **5V（脚 2/4）**：**LCD1602**、**HC-SR501**、（拓展）HC-SR04
> 把 5V 给 3.3V 器件可能烧器件；把 3.3V 给 LCD1602 会"几乎全黑"（对比度不足）。

**两条最重要的红线**

- **插拔任何杜邦线之前，先断电**（带电插拔最容易烧 GPIO；硬拔电源还会坏 SD 卡）。
- **所有器件必须与树莓派共地**（不共地的典型症状：读数乱跳、I2C 时通时不通）。

## 0.5 电源与 GND 逐器件对照（**接线时先看这张**）

树莓派上 **GND 共 8 个脚：6、9、14、20、25、30、34、39**（脚 6/9/14/20/25/30/34/39 都是同一个"地"）。
**所有器件的地最终都必须连到树莓派的这些脚之一**（互相之间怎么连无所谓，只要是同一个地）。

### 如果要逐个直插排针（不共用地轨）

| 器件 | 电源脚 | **GND 接到** |
| --- | --- | --- |
| MAX30102 | 脚 **1**（3.3V） | 脚 **6** |
| LCD1602 转接板 | 脚 **2**（5V） | 脚 **9** |
| DHT11 | 脚 **1**（3.3V） | 脚 **14** |
| HC-SR501 | 脚 **2**（5V） | 脚 **20** |
| TFT 彩屏 | 脚 **1**（3.3V） | 脚 **39** |
| LED 绿/黄（共阴） | —（阴极不接电源） | 脚 **39**（与 TFT、蜂鸣器共用一个 GND 脚即可） |
| 蜂鸣器 | —（`+` 接脚 12） | 脚 **39**（与 LED 共地即可） |
| 求救按键 | 一端接脚 13 | 另一端 → 脚 **25** |
| （拓展）HC-SR04 | 脚 **2**（5V） | 脚 **20**（与 HC-SR501 共用） |

> 8 个 GND 要分给 10 个器件，**必然有多个器件共用一个 GND 脚**（把若干根杜邦线拧在一个脚上，或走面包板地轨）。

### 推荐：用面包板地轨（最省事，也最不容易错）

```
树莓派脚 6（GND） ──一根线──> 面包板【蓝色地轨（−）】
树莓派脚 2（5V）  ──一根线──> 面包板【红色电源轨（+）】
树莓派脚 1（3.3V）──一根线──> 面包板【另一条独立的轨（例如黄色轨）】
```
然后**每个器件的 GND 都插到蓝色地轨上任意孔**即可（同一根轨上的孔是全部导通的）。

> ⚠️ 两条红线：
> 1. **红色轨（5V）与黄色轨（3.3V）绝不能连在一起**——会把 5V 灌进 3.3V，可能烧器件；
> 2. 面包板**每一列纵向也是导通的**，别把电源与信号插在同一列。

### 怎么验证"地真的共了"（万用表蜂鸣档）

黑表笔放在**树莓派脚 6（GND）**，红表笔依次点**每个器件的 GND 脚**：
**响（导通）= 共地正确**；不响 = 该器件的 GND 没接好（此时它的读数必然乱跳或读不到）。

## 2. 必接器件（六个）

### 2.1 MAX30102 心率血氧（I2C，地址 0x57 固定）

| 传感器脚 | 接树莓派物理脚 | 说明 |
| --- | --- | --- |
| VIN / VCC | 1 | 3.3V，**不要接 5V** |
| GND | 6 | |
| SDA | 3 | 与 LCD 共用同一根 SDA |
| SCL | 5 | 与 LCD 共用同一根 SCL |
| INT | 不接 | 本项目采用轮询读取 |

### 2.2 LCD1602 液晶（I2C 背包，地址 0x27 或 0x3F，程序自动探测）

| LCD 脚 | 接树莓派物理脚 | 说明 |
| --- | --- | --- |
| VCC | **2**（5V） | ⚠️ **必须 5V**！接 3.3V 时对比度极低、屏幕几乎全黑（驱动/权威文档均如此要求）|
| GND | 9 | |
| SDA | 3 | 与 MAX30102 并挂 |
| SCL | 5 | 与 MAX30102 并挂 |
| 背光跳线 | 保持短接 | 常亮，不占用 GPIO |

两个 I2C 器件共用 SDA/SCL 是正常的（总线式），不需要分开接。

### 2.3 DHT11 温湿度（单总线）

| DHT11 脚 | 接树莓派物理脚 | 说明 |
| --- | --- | --- |
| VCC (+) | 1 | 3.3V |
| DATA | 7 | GPIO4 |
| GND (−) | 14 | |
| 上拉电阻 | DATA 与 3.3V 之间 | 裸传感器需 4.7kΩ~10kΩ；模块小板通常已内置 |

### 2.4 HC-SR501 人体红外

| 模块脚 | 接树莓派物理脚 | 说明 |
| --- | --- | --- |
| VCC | **2**（5V） | ⚠️ **必须 5V**！接 3.3V 会工作不稳、误触发、探测距离明显变短 |
| OUT | **11**（GPIO17） | 输出 **3.3V 电平，可直连**，不需要电平转换 |
| GND | **20**（GND） | 必须共地，不共地读数必然乱跳 |

> 记忆点：**HC-SR501 是"5V 供电、3.3V 输出"**，而 HC-SR04 是"5V 供电、**5V** 输出"（后者必须加电平转换）。
> ⚠️ 市面上部分廉价仿制 HC-SR501 可能没有板载电平转换，若量到 OUT 为 5V 就必须加压降。

### 2.5 蜂鸣器

| 蜂鸣器 | 接树莓派物理脚 | 说明 |
| --- | --- | --- |
| +(长脚) | 12（GPIO18） | 串 100Ω~1kΩ 限流 |
| −(短脚) | **39（GND）** | 与 LED 共用一个 GND 脚即可 |

### 2.6 LED 状态灯（每个都要串 220Ω~1kΩ）

| LED | 阳极经电阻接 | 阴极接 | 含义 |
| --- | --- | --- | --- |
| 绿 | 15（GPIO22） | **39（GND）** | 一切正常 |
| 黄 | 16（GPIO23） | **39（GND）** | 需要注意 |
| ~~红~~ | ~~18（GPIO24）~~ | — | **本项目不接**：GPIO24 让给 TFT 的 A0（见 4.1） |

> 两个 LED 的阴极可以拧在一起接同一个 GND 脚（39），地是共通的。

### 2.7 求救按键

| 按键 | 接树莓派物理脚 | 说明 |
| --- | --- | --- |
| 一端 | 13（GPIO27） | |
| 另一端 | **34（GND）** | |
| 消抖电容（可选） | 与按键两端并联 0.1µF | 按键抖动大时加 |

程序已启用 GPIO27 内部上拉，**不需要**外接上拉电阻：按下即为低电平。

## 3. SPI 总线（本项目只挂 TFT 一个从设备）

**先说一个知识点**：树莓派**没有模拟输入脚**。早期计划用 **TMP36（模拟输出）+ MCP3002（SPI ADC）**
补上"精密体温"，该路线已于 **2026-09-28 由用户决定取消**、**相关代码与接线已于 2026-10-01 彻底删除**
（为什么取消、踩了什么坑，见 `ERROR.md` **E48**）。

于是 SPI0 上现在**只剩 TFT 一个从设备**：

| 项目 | 值 | 说明 |
| --- | --- | --- |
| 总线 | **SPI0**（`/dev/spidev0.1`） | 树莓派 5 默认 4 线 SPI0 |
| 片选 | **CE1 = GPIO7 = 物理脚 26** | TFT 的 CS |
| MISO（脚 21） | **空闲** | 本项目没有需要 MISO 的 SPI 器件 |
| CE0（脚 24） | **空闲** | 空着不用 |

⚠️ SPI 是**共享总线，每个从设备必须有自己的片选** —— 往后若要在 SPI0 上加器件，
请用**另一个片选**，**不要与 TFT 共用脚 26**。

## 4. TFT 彩屏 1.8 寸（丝印 1.8TFT SPI 128*160，控制器 ST7735S）

| TFT 丝印 | 接树莓派物理脚 | 说明 |
| --- | --- | --- |
| VCC | 1 | 3.3V |
| GND | **25** | GND（见第 0.5 节的 GND 分配） |
| SCK | 23 | GPIO11 / SPI0 SCLK |
| SDA | 19 | GPIO10 / SPI0 MOSI |
| CS | 26 | GPIO7 / CE1，独占 |
| A0 | 18 | GPIO24，即 DC／RS（命令与数据选择） |
| RESET | 22 | GPIO25 |
| LED | 17 | 3.3V 背光常亮 |

### 4.1 撞脚问题：**已于 2026-09-26 解决**（红灯改接脚 32）

历史：早期**红灯**用 GPIO24（脚 18），而 TFT 的 **A0** 也是 GPIO24 ⇒ 两者不能同时接。
**2026-09-26 起红灯改接 GPIO12（物理脚 32）**（`rpi/config/devices.json` 里
`status_led.pins.red = 12`），所以**现在 TFT（脚 18）与三色指示灯可以同时接**。

⚠️ 本节此前的版本写着"**建议不接红灯**"（方案 B）—— **那条已作废**，别再照它做。
（当初的方案 A/B/C 取舍保留在 `docs/14` 的分级记录里供追溯，见 T2 那一轮。）

唯一还需要当心的"撞脚"是**片选**：**TFT 的 CS 必须用脚 26（CE1）**，
SPI 是总线式，往后加器件请另用一个片选（CE0=脚 24 现在空着）。

## 5. 拓展件（默认关闭，先不要接）

### 5.1 HC-SR04 超声波测距

| HC-SR04 | 接哪 | 说明 |
| --- | --- | --- |
| VCC | 物理脚 2（5V） | 该模块需 5V |
| TRIG | 物理脚 29（GPIO5） | 3.3V 触发信号，可直接接 |
| ECHO | 经 TXS0102 后接物理脚 31（GPIO6） | Echo 输出 5V，直连会损坏 GPIO |
| GND | 物理脚 39 | |

没有 TXS0102 时可用电阻分压代替：ECHO → 1kΩ → GPIO6，同时 GPIO6 → 2kΩ → GND。

## 6. 安全与供电红线（务必读完）

| 事项 | 要求 |
| --- | --- |
| 断电插拔 | 任何接线、改线**先断电**（拔电源或 `sudo poweroff`） |
| 共地 | 所有器件 GND 必须与树莓派 GND 相连 |
| 电压 | MAX30102、LCD、DHT11、TFT 均为 3.3V 器件，**不要接 5V** |
| 限流 | LED 串 220Ω~1kΩ；蜂鸣器串 100Ω~1kΩ |
| 电流预算 | 全接上约 100~150 mA，树莓派 3.3V 轨上限约 500 mA，够用但不要长期满载 |
| 背光 | TFT 背光建议接 5V（串限流电阻）或单独供电，减轻 3.3V 轨压力 |
| 静电 | 拿板子前先摸一下接地金属，避免静电击穿 |
| 杜邦线 | 优先用母对母、插紧；接触不良是"时好时坏"的最常见原因 |

## 7. 分步接线顺序（建议严格按此顺序）

| 步骤 | 接什么 | 通电后怎么验 |
| --- | --- | --- |
| 1 | MAX30102 + LCD1602（I2C） | `sudo /usr/sbin/i2cdetect -y 1` 应见 0x57 与 0x27（或 0x3f） |
| 2 | DHT11（脚7）+ HC-SR501（脚11） | `python3 -m health_monitor selfcheck --real` |
| 3 | LED(15/16/18) + 蜂鸣器(12) + 按键(13) | `sudo python3 scripts/hardware_test.py` |
| 4 | TFT（CE1 + A0 + RESET） | `python3 scripts/tft_check.py --steps`，看三色条是否正确 |
| 5 | （可选）HC-SR04 | 需电平转换，见第 5 节 |

每步只加一类器件，出问题时容易定位：**一次全接上，出问题要排查的点会多很多**。

## 9. 常见现象与对应接线原因

| 现象 | 最可能的原因 |
| --- | --- |
| I2C 一个都扫不到 | SDA/SCL 接反、没共地、器件没供电 |
| 扫到 0x57 但读不到心率 | 手指未覆盖传感器、强光直射、等待时间不足 10 秒 |
| 扫到 0x27 但 LCD 不显示 | 对比度电位器没调、背光跳线未短接 |
| DHT11 一直返回缓存值 | 读取间隔小于 2 秒（本驱动已限制为 3 秒） |
| TFT 花屏或全白 | 控制器型号选错、SPI 时钟过快、DC/RST 接错 |
| TFT 颜色红蓝互换 | 需要开启 BGR 选项 |
| 按键不响应 | 一端未接 GND、按下的确为低电平但引脚号写错 |
| 蜂鸣器一直响 | 引脚号错、驱动了三极管型模块的高电平触发端 |
