# 树莓派健康监护系统 · 接线总表

**项目**：raspberry-health-monitor（树莓派居家老人健康与安全监护系统）
**平台**：Raspberry Pi 5 Model B Rev 1.1 ／ Debian 13 (trixie) ／ Python 3.13.5
**生成日期**：2026-09-24
**依据**：`rpi/config/devices.json` 与 `rpi/health_monitor/hal/pins.py`（**引脚号从代码读取，非手写**）
**校验**：`python3 scripts/validate.py` 第 5 项「引脚冲突」通过（7 个独占引脚无冲突）

## 0. 三分钟总览

| 总线 | 器件 | 地址／片选 | 关键物理脚 |
| --- | --- | --- | --- |
| I2C1 | MAX30102 心率血氧 | 0x57 | 3(SDA) / 5(SCL) |
| I2C1 | LCD1602 液晶 | 0x27 或 0x3F（自动探测） | 3(SDA) / 5(SCL) |
| 单总线 | DHT11 温湿度 | — | 7 (GPIO4) |
| GPIO | HC-SR501 人体红外 | — | VCC=2(5V) / OUT=11(GPIO17) / GND=6 |
| SPI0 | MCP3002 ADC（带 TMP36） | CE0 = 脚24 | 19/21/23/24 |
| SPI0 | TFT 彩屏 1.8 寸 | CE1 = 脚26 | 19/23/26/18/22 |
| GPIO | 蜂鸣器 | — | 12 (GPIO18) |
| GPIO | LED 绿／黄／红 | — | 15 / 16 / 18 |
| GPIO | 求救按键 | — | 13 (GPIO27) |
| GPIO | （拓展）HC-SR04 超声波 | — | 29 / 31 + 电平转换 |

> 供电原则（**照这个接，别照别的**）：
> **3.3V（脚 1/17）**：MAX30102、DHT11、TMP36、MCP3002、TFT
> **5V（脚 2/4）**：**LCD1602**、**HC-SR501**、（拓展）HC-SR04
> 把 5V 给 3.3V 器件可能烧器件；把 3.3V 给 LCD1602 会"几乎全黑"（对比度不足）。

**两条最重要的红线**

- **插拔任何杜邦线之前，先断电**（带电插拔最容易烧 GPIO；硬拔电源还会坏 SD 卡）。
- **所有器件必须与树莓派共地**（不共地的典型症状：读数乱跳、I2C 时通时不通）。

| GND (−) | 14 | |

### 2.4 HC-SR501 人体红外

| 模块脚 | 接树莓派物理脚 | 说明 |
| --- | --- | --- |

## 3. SPI 器件：TMP36 精密测温

**原理必须先讲清楚**：树莓派**没有模拟输入脚**。TMP36 输出的是模拟电压，
所以**必须**经过 MCP3002 这个 ADC 芯片，程序读的是 ADC 转换结果。

### 3.1 MCP3002（ADC，使用 CE0）

| MCP3002 脚 | 接树莓派物理脚 | 说明 |
| --- | --- | --- |
| VDD / VCC | 1 | 3.3V |
| VSS / GND | 6 | |
| CLK | 23 | GPIO11 / SCLK |
| DIN | 19 | GPIO10 / MOSI |
| DOUT | 21 | GPIO9 / MISO |
| CS | 24 | GPIO8 / CE0，独占 |
| CH0 | ← TMP36 VOUT | 体温通道 |
| CH1 | 空闲 | 可接 10kΩ 电位器做拓展 |

### 3.2 TMP36（模拟温度，接 CH0）

| TMP36 脚 | 接哪 | 说明 |
| --- | --- | --- |
| 左脚 (+Vs) | 物理脚 1（3.3V） | |
| 中脚 (VOUT) | MCP3002 的 CH0 | |
| 右脚 (GND) | 物理脚 6（GND） | |
| 去耦电容 | V+ 与 GND 之间并 0.1µF | 强烈建议，能明显稳住读数 |

注意：TMP36 与 MCP3002 必须共地，且都用 3.3V。用 5V 给 ADC 会超出其输入范围。

#### 3.2.1 先确认封装（决定能不能直接插面包板）

| 封装 | 长相 | 怎么办 |
| --- | --- | --- |
| **TO-92** | 三脚直插小黑块（像普通三极管） | ✅ 直接插面包板 |
| **SOT-23** | 贴片（米粒大小、无长脚） | ⚠️ **必须焊到 SOT-23 转 DIP 转接板**才能插面包板 |

#### 3.2.2 认脚方向（插反会读数离谱）

拿 TMP36 时**平面（有字的那面）朝自己**，三只脚从左到右依次是：

```
   ┌─────────┐
   │  TMP36  │   ← 平面朝自己
   └─┬──┬──┬─┘
     │  │  │
    1   2   3
   +Vs VOUT GND
   (3.3V) (→CH0) (GND)
```

#### 3.2.3 最容易错的一点：公式里必须减掉 0.5V 偏移

TMP36 的输出**不是**"电压直接对应温度"，而是带有 **500 mV 的固定偏移**：

```
温度(℃) = (Vout 毫伏 − 500) / 10
```

例：Vout = 750 mV ⇒ (750 − 500)/10 = **25.0 ℃**。

**判断有没有踩这个坑**：室温下如果读数显示 **50 ℃ 左右**，就是漏减了 0.5V；
显示 **0 ℃ 附近**说明接线或通道选错。

本项目驱动 `sensors/tmp36.py` 已按上式实现，并用 `calibration_offset_c` 做单点校准
（默认 0，读数有固定偏差时改它）。

## 4. TFT 彩屏 1.8 寸（丝印 1.8TFT SPI 128*160，控制器 ST7735S）

| TFT 丝印 | 接树莓派物理脚 | 说明 |
| --- | --- | --- |
| VCC | 1 | 先试 3.3V |
| GND | 6 | |
| SCK | 23 | 与 MCP3002 共用 SPI 时钟 |
| SDA | 19 | 与 MCP3002 共用 MOSI |
| CS | 26 | GPIO7 / CE1，独占 |
| A0 | 18 | GPIO24，即 DC／RS（命令与数据选择） |
| RESET | 22 | GPIO25 |
| LED | 17 | 3.3V 背光常亮 |

### 4.1 必须先解决的撞脚问题

状态灯的**红灯**用 GPIO24（物理脚 18），而 TFT 的 **A0** 也是 GPIO24：
**两者不能同时接**。三种取舍：

| 方案 | 做法 | 评价 |
| --- | --- | --- |
| A | 把 TFT 的 A0/RESET 改接空闲 GPIO 并改配置 | 需要改代码配置，最灵活 |
| B | **不接红灯**，只保留绿/黄，把 GPIO24 让给 TFT | **推荐**：现场最省事，报警状态仍由 LCD/TFT/蜂鸣器表达 |
| C | 状态灯与 TFT 二选一 | 会丢掉 LED 指示 |

若选方案 B，把 `rpi/config/devices.json` 里 `status_led.pins` 的 `red` 删掉即可。

### 4.2 TFT 与 MCP3002 可以同时接

SPI 是总线式，支持多个从设备，前提是**片选分开**：MCP3002 用 CE0（脚 24）、
TFT 用 CE1（脚 26）。这一点本项目已配置好，不需要额外处理。

## 5. 拓展件（默认关闭，先不要接）

### 5.1 HC-SR04 超声波测距

| HC-SR04 | 接哪 | 说明 |
| --- | --- | --- |
| VCC | 物理脚 2（5V） | 该模块需 5V |
| TRIG | 物理脚 29（GPIO5） | 3.3V 触发信号，可直接接 |
| ECHO | 经 TXS0102 后接物理脚 31（GPIO6） | Echo 输出 5V，直连会损坏 GPIO |
| GND | 物理脚 39 | |

没有 TXS0102 时可用电阻分压代替：ECHO → 1kΩ → GPIO6，同时 GPIO6 → 2kΩ → GND。

## 6. 安全与供电红线（务必读完）

| 事项 | 要求 |
| --- | --- |
| 断电插拔 | 任何接线、改线**先断电**（拔电源或 `sudo poweroff`） |
| 共地 | 所有器件 GND 必须与树莓派 GND 相连 |
| 电压 | MAX30102、LCD、MCP3002、TMP36、DHT11 均为 3.3V 器件，**不要接 5V** |
| 限流 | LED 串 220Ω~1kΩ；蜂鸣器串 100Ω~1kΩ |
| 电流预算 | 全接上约 100~150 mA，树莓派 3.3V 轨上限约 500 mA，够用但不要长期满载 |
| 背光 | TFT 背光建议接 5V（串限流电阻）或单独供电，减轻 3.3V 轨压力 |
| 静电 | 拿板子前先摸一下接地金属，避免静电击穿 |
| 杜邦线 | 优先用母对母、插紧；接触不良是"时好时坏"的最常见原因 |

## 7. 分步接线顺序（建议严格按此顺序）

| 步骤 | 接什么 | 通电后怎么验 |
| --- | --- | --- |
| 1 | MAX30102 + LCD1602（I2C） | `sudo /usr/sbin/i2cdetect -y 1` 应见 0x57 与 0x27（或 0x3f） |
| 2 | DHT11（脚7）+ HC-SR501（脚11） | `python3 -m health_monitor selfcheck --real` |
| 3 | LED(15/16/18) + 蜂鸣器(12) + 按键(13) | `sudo python3 scripts/hardware_test.py` |
| 4 | MCP3002 + TMP36（SPI CE0） | 体温读数应在 35~38 ℃ 之间 |
| 5 | TFT（CE1 + A0 + RESET） | `python3 scripts/tft_check.py --steps`，看三色条是否正确 |
| 6 | （可选）HC-SR04 | 需电平转换，见第 5 节 |

每步只加一类器件，出问题时容易定位：**一次全接上，出问题要排查的点会多很多**。

## 9. 常见现象与对应接线原因

| 现象 | 最可能的原因 |
| --- | --- |
| I2C 一个都扫不到 | SDA/SCL 接反、没共地、器件没供电 |
| 扫到 0x57 但读不到心率 | 手指未覆盖传感器、强光直射、等待时间不足 10 秒 |
| 扫到 0x27 但 LCD 不显示 | 对比度电位器没调、背光跳线未短接 |
| TMP36 读数恒定不变 | VOUT 未接到 CH0、CH0 与 CH1 弄反、未共地 |
| TMP36 读数约 50 ℃ | **公式漏减 0.5V 偏移**（见 3.2.3），或 ADC 参考电压设错 |
| TMP36 读数约 0 ℃ | VOUT 接到 GND、通道选错（读的是悬空的 CH1） |
| TMP36 读数跳得厉害 | 缺 0.1µF 去耦电容、杜邦线接触不良、电源噪声 |
| TMP36 读数高 1~2 ℃ | 属正常（自身发热 + 3.3V 供电偏置），可用 `calibration_offset_c` 单点校准 |
| DHT11 一直返回缓存值 | 读取间隔小于 2 秒（本驱动已限制为 3 秒） |
| TFT 花屏或全白 | 控制器型号选错、SPI 时钟过快、DC/RST 接错 |
| TFT 颜色红蓝互换 | 需要开启 BGR 选项 |
| 按键不响应 | 一端未接 GND、按下的确为低电平但引脚号写错 |
| 蜂鸣器一直响 | 引脚号错、驱动了三极管型模块的高电平触发端 |
