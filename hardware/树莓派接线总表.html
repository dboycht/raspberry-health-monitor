供电原则（照这个接，别照别的）：

5V（脚 2/4）：LCD1602、HC-SR501、（拓展）HC-SR04
把 5V 给 3.3V 器件可能烧器件；把 3.3V 给 LCD1602 会"几乎全黑"（对比度不足）。

两条最重要的红线

  • 插拔任何杜邦线之前，先断电（带电插拔最容易烧 GPIO；硬拔电源还会坏 SD 卡）。
  • 所有器件必须与树莓派共地（不共地的典型症状：读数乱跳、I2C 时通时不通）。

0.5 电源与 GND 逐器件对照（接线时先看这张）

树莓派上 GND 共 8 个脚：6、9、14、20、25、30、34、39（脚 6/9/14/20/25/30/34/39 都是同一个"地"）。
所有器件的地最终都必须连到树莓派的这些脚之一（互相之间怎么连无所谓，只要是同一个地）。

如果要逐个直插排针（不共用地轨）

8 个 GND 要分给 10 个器件，必然有多个器件共用一个 GND 脚（把若干根杜邦线拧在一个脚上，或走面包板地轨）。

推荐：用面包板地轨（最省事，也最不容易错）

树莓派脚 6（GND） ──一根线──> 面包板【蓝色地轨（−）】
树莓派脚 2（5V）  ──一根线──> 面包板【红色电源轨（+）】
树莓派脚 1（3.3V）──一根线──> 面包板【另一条独立的轨（例如黄色轨）】

然后每个器件的 GND 都插到蓝色地轨上任意孔即可（同一根轨上的孔是全部导通的）。

⚠️ 两条红线：
1. 红色轨（5V）与黄色轨（3.3V）绝不能连在一起——会把 5V 灌进 3.3V，可能烧器件；
2. 面包板每一列纵向也是导通的，别把电源与信号插在同一列。

怎么验证"地真的共了"（万用表蜂鸣档）

黑表笔放在树莓派脚 6（GND），红表笔依次点每个器件的 GND 脚：
响（导通）= 共地正确；不响 = 该器件的 GND 没接好（此时它的读数必然乱跳或读不到）。

3. SPI 器件：TMP36 精密测温

原理必须先讲清楚：树莓派没有模拟输入脚。TMP36 输出的是模拟电压，
所以必须经过 MCP3002 这个 ADC 芯片，程序读的是 ADC 转换结果。

3.1 MCP3002（ADC，使用 CE0）

MCP3002 脚接树莓派物理脚说明
VDD / VCC13.3V
VSS / GND30GND（见第 0.5 节的 GND 分配）
CLK23GPIO11 / SCLK
DIN19GPIO10 / MOSI
DOUT21GPIO9 / MISO
CS24GPIO8 / CE0，独占
CH0← TMP36 VOUT体温通道
CH1空闲可接 10kΩ 电位器做拓展

3.2 TMP36（模拟温度，接 CH0）

TMP36 脚接哪说明
左脚 (+Vs)物理脚 1（3.3V）
中脚 (VOUT)MCP3002 的 CH0
右脚 (GND)物理脚 34（GND）与树莓派共地
去耦电容V+ 与 GND 之间并 0.1µF强烈建议，能明显稳住读数

注意：TMP36 与 MCP3002 必须共地，且都用 3.3V。用 5V 给 ADC 会超出其输入范围。

3.2.1 先确认封装（决定能不能直接插面包板）

封装长相怎么办
TO-92三脚直插小黑块（像普通三极管）✅ 直接插面包板
SOT-23贴片（米粒大小、无长脚）⚠️ 必须焊到 SOT-23 转 DIP 转接板才能插面包板

3.2.2 认脚方向（插反会读数离谱）

拿 TMP36 时平面（有字的那面）朝自己，三只脚从左到右依次是：

   ┌─────────┐
   │  TMP36  │   ← 平面朝自己
   └─┬──┬──┬─┘
     │  │  │
    1   2   3
   +Vs VOUT GND
   (3.3V) (→CH0) (GND)

3.2.3 最容易错的一点：公式里必须减掉 0.5V 偏移

TMP36 的输出不是"电压直接对应温度"，而是带有 500 mV 的固定偏移：

温度(℃) = (Vout 毫伏 − 500) / 10

例：Vout = 750 mV ⇒ (750 − 500)/10 = 25.0 ℃。

判断有没有踩这个坑：室温下如果读数显示 50 ℃ 左右，就是漏减了 0.5V；
显示 0 ℃ 附近说明接线或通道选错。

本项目驱动 sensors/tmp36.py 已按上式实现，并用 calibration_offset_c 做单点校准
（默认 0，读数有固定偏差时改它）。

4.1 必须先解决的撞脚问题

状态灯的红灯用 GPIO24（物理脚 18），而 TFT 的 A0 也是 GPIO24：
两者不能同时接。三种取舍：

方案做法评价
A把 TFT 的 A0/RESET 改接空闲 GPIO 并改配置需要改代码配置，最灵活
B不接红灯，只保留绿/黄，把 GPIO24 让给 TFT推荐：现场最省事，报警状态仍由 LCD/TFT/蜂鸣器表达
C状态灯与 TFT 二选一会丢掉 LED 指示

若选方案 B，把 rpi/config/devices.json 里 status_led.pins 的 red 删掉即可。

4.2 TFT 与 MCP3002 可以同时接

SPI 是总线式，支持多个从设备，前提是片选分开：MCP3002 用 CE0（脚 24）、
TFT 用 CE1（脚 26）。这一点本项目已配置好，不需要额外处理。

6. 安全与供电红线（务必读完）

事项要求
断电插拔任何接线、改线先断电（拔电源或 sudo poweroff）
共地所有器件 GND 必须与树莓派 GND 相连
电压MAX30102、LCD、MCP3002、TMP36、DHT11 均为 3.3V 器件，不要接 5V
限流LED 串 220Ω~1kΩ；蜂鸣器串 100Ω~1kΩ
电流预算全接上约 100~150 mA，树莓派 3.3V 轨上限约 500 mA，够用但不要长期满载
背光TFT 背光建议接 5V（串限流电阻）或单独供电，减轻 3.3V 轨压力
静电拿板子前先摸一下接地金属，避免静电击穿
杜邦线优先用母对母、插紧；接触不良是"时好时坏"的最常见原因

7. 分步接线顺序（建议严格按此顺序）

步骤接什么通电后怎么验
1MAX30102 + LCD1602（I2C）sudo /usr/sbin/i2cdetect -y 1 应见 0x57 与 0x27（或 0x3f）

3LED(15/16/18) + 蜂鸣器(12) + 按键(13)sudo python3 scripts/hardware_test.py

9. 常见现象与对应接线原因

现象最可能的原因
I2C 一个都扫不到SDA/SCL 接反、没共地、器件没供电
扫到 0x57 但读不到心率手指未覆盖传感器、强光直射、等待时间不足 10 秒
扫到 0x27 但 LCD 不显示对比度电位器没调、背光跳线未短接
TMP36 读数恒定不变VOUT 未接到 CH0、CH0 与 CH1 弄反、未共地
TMP36 读数约 50 ℃公式漏减 0.5V 偏移（见 3.2.3），或 ADC 参考电压设错
TMP36 读数约 0 ℃VOUT 接到 GND、通道选错（读的是悬空的 CH1）
TMP36 读数跳得厉害缺 0.1µF 去耦电容、杜邦线接触不良、电源噪声
TMP36 读数高 1~2 ℃属正常（自身发热 + 3.3V 供电偏置），可用 calibration_offset_c 单点校准
DHT11 一直返回缓存值读取间隔小于 2 秒（本驱动已限制为 3 秒）
TFT 花屏或全白控制器型号选错、SPI 时钟过快、DC/RST 接错
TFT 颜色红蓝互换需要开启 BGR 选项
按键不响应一端未接 GND、按下的确为低电平但引脚号写错
蜂鸣器一直响引脚号错、驱动了三极管型模块的高电平触发端
