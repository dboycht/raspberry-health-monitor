## 1. 验收前的准备（三步）

```bash

sudo apt install -y python3-matplotlib python3-tk python3-lgpio fonts-noto-cjk

# ② 接线：VCC=3.3V（物理脚 1/17）、DATA=GPIO4（物理脚 7）、GND=任意 GND（推荐脚 6）
#    四针裸传感器要在 DATA 与 3.3V 之间接 4.7kΩ~10kΩ 上拉电阻
#    接线就看这一份（两张表）：basic/hardware/接线表.md

# ③ 自检（不接硬件也能跑；接好硬件后再跑一次确认后端选到了 lgpio）
cd ~/raspberry-health-monitor/basic
python3 tools/selfcheck.py            # 10 项
python3 tools/diag_dht_line.py        # 数据线三态电平（读不到数时用它定位）
```

## 3. 三条命令与"应该看到什么"

### ① 真实读取（答辩主场景）

```bash
cd ~/raspberry-health-monitor/basic
python3 run.py
```

```
数据源：DHT11 · GPIO4（物理脚 7，常用作 1-Wire / DHT 数据脚（DHT11 默认就接这里））　后端：lgpio
数据存档：/home/pi/raspberry-health-monitor/basic/data/dht11_20260924_201503.csv
[20:15:03] #   1　温度: 25.0 ℃，湿度: 58 %
[20:15:06] #   2　温度: 25.1 ℃，湿度: 57 %
...
窗口已打开：关闭窗口即退出（数据同时打印在本终端）
```

曲线窗口上应当看到：标题是"最新一次读数　温度: 25.0 ℃　湿度: 58 %"，
红蓝两条曲线随时间向前延伸，底部两行状态行写明数据源、采样周期、累计样本与范围。

> 结束时按 `Ctrl+C` 或关窗口。**已经采集的数据都已经落进 CSV**（每行即时 fsync）。

### ② 没有硬件/没有树莓派时（合成数据）

```bash
python3 run.py --mock --duration 20 --save curve.png
```

判据：20 秒后导出 `curve.png`，终端打印"共采集 N 个样本"，
曲线形状是缓慢波动的室内温湿度（24~27 ℃ / 45~57 %）。

### ③ 离线回放（验证"读 → 存 → 画"链路，用仓库里的演示数据）

```bash
python3 run.py --replay --headless --save curve.png
python3 run.py --replay            # 带窗口逐点回放（约 0.15 s 一个点）
```

## 4. 曲线样张（截图证据）

[`evidence/curve_demo.png`](evidence/curve_demo.png) 由下面这条命令生成（**合成数据**，
用于说明"图上应该有什么"；不代表任何真实测量结果）：

```bash
cd basic
python3 run.py --replay --headless --save evidence/curve_demo.png
```

图上必须能看到：标题里的最新读数、红/蓝双曲线、左右两套纵轴（℃ / %）、
横轴的"时间 (秒)"、底部两行状态行（数据源 / 采样周期 / 累计样本 / 温度湿度范围）。

> ⚠️ 诚实标注：这张图是 **mock 合成数据**画出来的。
> 报告里若要放"真实读数曲线"，请在树莓派上跑 `python3 run.py --no-plot --duration 300`
> 或直接 `python3 run.py --save real_curve.png` 得到真实数据版本，并注明采集时间与地点。
