## 1. 作业要求（老师题目原文）

> **H：温湿度测量**
>
> **核心任务**：使用树莓派 5 和课程中学习过的温湿度传感器（如 DHT11）周期性读取温度和湿度。
> 程序保存连续采集的数据，并用 **Matplotlib 绘制动态曲线**；每得到一组新数据，
> 图中的曲线随之刷新。图中应明确标出温度、湿度以及采样顺序或时间，
> 使读者能够观察环境参数随时间的变化趋势。
>
> **示例输出**：运行后出现动态曲线窗口，温度曲线和湿度曲线随着新数据不断向前延伸。
> 例如最新一次数据为"温度: 25.0 ℃，湿度: 58%"，下一次采样后图中增加一个新的数据点。

## 5. 重要：怎么才能"看到弹窗"（**实测踩过，别白折腾**）

作业要求"运行后出现动态曲线窗口"。**如果你通过 SSH 连树莓派跑，窗口不会出现**，原因是两个（都在真机上实测确认）：

| 检查项 | 实测结果 |
| --- | --- |
| 树莓派有没有桌面 | **有**（labwc/Wayland + Xwayland 在 `:0`，lightdm 已装） |
| SSH 会话环境 | `DISPLAY=<空>`、`XDG_SESSION_TYPE=tty` ⇒ matplotlib 只能选 `agg` 后端（**只出图片文件，不弹窗**，而且它**不报错**） |
| 强行 `DISPLAY=:0` | 仍失败：`ImportError: cannot import name 'ImageTk' from 'PIL'` ⇒ **缺 `python3-pil.imagetk`** |

**两步解决**：

```bash
# ① 补上缺的 Tk 图像组件（需要输入密码）
sudo apt install -y python3-pil.imagetk
```

```bash
# ② 在有 DISPLAY 的环境里跑（三选一）
# A. 推荐：在树莓派自己的桌面里开终端
cd /home/pi/basic/hw && python3 run.py

# B. 仍用 SSH，但把 DISPLAY 指过去（窗口出现在树莓派接的显示器上）
DISPLAY=:0 python3 run.py

# C. 你的电脑装 X server（VcXsrv/Xming），用 ssh -Y pi@<树莓派IP> 连再跑（窗口出现在电脑上）
```

**没有窗口也能交作业**：用 `--headless --save 图片.png` 导出曲线图（本次交付的证据图就是这么来的）。
程序在开不了窗口时**会主动打印原因和对应命令**（不会静默降级）。

## 7. 期间修掉的问题（**都在代码里，不是硬件**）

这套代码在真机上跑通过程中暴露并修掉了 4 个问题，写在这里是为了**后人不必再踩**：

| 编号 | 现象 | 根因 | 修法 |
| --- | --- | --- | --- |
| E37 | 稳定"只解出 39/40 个 bit" | DHT11 传完后上拉会把总线拉回空闲，产生**一个多余的上升沿**（整帧 83 边沿）；解码器按"从第 1 个边沿配对"会错位一格 | 改成**取最后 41 对**（应答 1 + 数据 40），不足则报"帧不完整" |
| E38 | `run.py` "隔一次读不到" | 把**采样周期**当成了驱动的最小间隔（3.0 秒门禁 vs 实际 2.94 秒） | 门禁用**硬件下限 2 秒**，采样节奏交给主循环的 `--interval` |
| E39 | 图里中文/数字变方框 | ① 树莓派自带中文字体 `DroidSansFallback` **只有 CJK 字形、没有数字**；② matplotlib 在文本内部不做逐字回退；③ 只设 `rcParams` 时"刷新/换 DPI 导出"会退回默认字体 | ① 换成"拉丁+中文都全"的 Noto（随包）；② 字体链**拉丁在前**；③ 把字体属性**直接挂到每个文本对象** |
| — | 窗口静默不出现 | 没有 `DISPLAY` 时 matplotlib **静默**退到 `agg`，不抛异常 | 主动检查后端名，开不了窗口就打印原因 + 命令 |

> 详细的排查过程（现象→排查→根因→修复）在开发副本的 `ERROR.md`（E36~E39），
> 按约定**不随交付包分发**；如果你要，我可以单独给你那份。
