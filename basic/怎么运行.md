# 基础版（课程作业 H）怎么在树莓派上运行

> 这一份是**给你照着敲**的。所有路径都是**树莓派上的绝对路径**。

## 0. 一句话

作业的入口是 **`/home/pi/raspberry-health-monitor/basic/run.py`** ——
它的工作目录必须是 `/home/pi/raspberry-health-monitor/basic`，
所以先 `cd` 进去再 `python3 run.py`。

## 1. 文件都在哪

```
/home/pi/raspberry-health-monitor/          ← 整个项目（仓库根）
└── basic/                                  ← ★ 作业只用到这个文件夹
    ├── run.py                              ← ★★ 入口：从这里启动
    ├── plot.py                             动态曲线 + 采集主循环（run.py 调它）
    ├── dht11read.py                        DHT11 读取（lgpio 单总线）
    ├── store.py / model.py                 CSV 存档与一条采样记录
    ├── series.py                           曲线数据窗口（滚动/统计）
    ├── pins.py / wire_spec.py              引脚与接线事实（唯一来源）
    ├── console.py                          中文控制台打印的安全网
    ├── data/                               ① 运行时采集的 CSV 存这里
    ├── evidence/                           ② 作业证据（真机曲线图 + 111 样本 CSV）
    ├── fonts/                              Noto Sans CJK 字体（中文图靠它）
    ├── hardware/接线表.pdf                  ③ 接线就看这一份
    ├── tools/selfcheck.py / diag_dht_line.py / wire_docs.py
    └── tests/                              单测（不用硬件）
```

> `rpi/`（完整监护系统）与本次作业**无关**，不用管它；只有
> `rpi/scripts/validate.py` 会在"提交前检查"时把基础版一起验一遍。

## 2. 最常用的四条命令（先在树莓派上敲第 0 条）

```bash
# 0) 每次都要先进入这个目录（run.py 依赖"当前目录在 basic/"）
cd /home/pi/raspberry-health-monitor/basic

# 1) 自检（不接硬件也能跑；接好硬件后再跑一次，应看到"后端：lgpio"）
python3 tools/selfcheck.py

# 2) 【作业正片】真机读取 + 弹出动态曲线窗口（需要桌面环境）
python3 run.py

# 3) 没有显示器（SSH 里跑）：只采集存 CSV，不弹窗
python3 run.py --no-plot --interval 3 --duration 300

# 4) 不接硬件也能看曲线（合成数据 / 回放已有 CSV）
python3 run.py --mock
python3 run.py --replay data/dht11_20260925_211419.csv
```

## 2.1 单文件版（**只想交一个 .py 就用这个**）

如果老师要求"一个运行入口文件"，用这个：**`/home/pi/raspberry-health-monitor/basic/hw/run.py`**
—— 单文件自包含（DHT11 读取 + CSV 存档 + Matplotlib 动态曲线全在里面，不 import 项目其它模块）。

```bash
cd /home/pi/raspberry-health-monitor/basic/hw

python3 run.py                              # 真机读取 + 动态曲线窗口
python3 run.py --no-plot --duration 300     # SSH 无桌面：只采集存 CSV
python3 run.py --headless --save curve.png  # 无桌面：采集并导出曲线图
python3 run.py --mock                       # 没接传感器也能看效果
python3 run.py --xaxis index                # 横轴改成"采样序号"
python3 run.py --help                       # 全部参数
```

- 数据存到 `hw/data/dht11_日期_时刻.csv`（每行即时落盘）；
- 中文字体在 `hw/fonts/`（随文件附带；删了图里中文会变方框，程序会提醒你装 `fonts-noto-cjk`）；
- **实测**（2026-09-26 树莓派）：真机读到 `24.1 ℃ / 60 %`，导出 PNG 的中文与数字都正常。

## 3. 出图（报告插图用）

```bash
cd /home/pi/raspberry-health-monitor/basic

# 真机采一轮 → 存 CSV；再把 CSV 回放成图片
python3 run.py --no-plot --interval 3 --duration 60
python3 run.py --replay data/dht11_20260925_211419.csv --window 200 --save /tmp/my_curve.png
```

`--save` 指定图片路径；`--headless` 表示"不弹窗、直接画到文件"。

## 4. 常用参数

| 参数 | 作用 |
| --- | --- |
| `--interval 3` | 采样间隔（秒）。**不要小于 2**（DHT11 硬件限制，程序会自动抬到 2） |
| `--duration 60` | 采集多少秒后自动退出（0 = 一直跑到你关窗口/Ctrl+C） |
| `--window 120` | 曲线窗口保留多少个点（默认 120） |
| `--xaxis index` | 横轴从"时间(秒)"改成"采样序号" |
| `--save 路径` | 把曲线导出成 PNG |
| `--no-plot` | 不画图，只采集 + 存 CSV |
| `--headless` | 不弹窗（配合 `--duration` / `--save`） |
| `--mock` | 用合成数据（没接传感器时） |
| `--replay [CSV]` | 回放已有 CSV（不带路径则用演示数据） |
| `--pin 4` | 数据脚 BCM 编号（默认 4 = 物理脚 7） |
| `--interval` 等 | `python3 run.py --help` 看全部 |

## 5. 结果存在哪

| 产物 | 位置 |
| --- | --- |
| 采集的 CSV | `basic/data/dht11_日期_时刻.csv`（一次运行一个文件） |
| 运行小结（样本数/成功/失败/范围） | 同目录 `dht11_日期_时刻.summary.json` |
| 曲线图片 | `--save` 指定的路径（例：`/tmp/my_curve.png`） |
| 作业证据（已入库） | `basic/evidence/`（真机曲线 + 111 样本 CSV） |

## 6. 出问题时

| 现象 | 怎么办 |
| --- | --- |
| `❌ 打不开 DHT11：没有可用的 DHT11 读取后端` | 在电脑上跑要加 `--mock`；树莓派上装 `sudo apt install -y python3-lgpio` |
| 每行都"本次没读到数据" | 先量接线（DATA=物理脚 7、VCC=脚 1 3.3V、GND=脚 6），再跑 `python3 tools/diag_dht_line.py` |
| 图里中文是方框 | 确认 `basic/fonts/NotoSansCJK-Regular.ttc` 还在；或 `sudo apt install -y fonts-noto-cjk` |
| 想确认代码/文档没被改坏 | `cd /home/pi/raspberry-health-monitor/rpi && python3 scripts/validate.py`（11 项全 PASS 才算好） |
