# 01 · 上机准备（树莓派刚到手 → 能远程敲命令）

> **目标**：树莓派能开机、能 SSH、I2C/SPI 已开、依赖已装、时间正确。
> **预计 40 分钟**（主要时间花在烧录系统与下载依赖）。
> **做完的判据**：本文最后一节的 6 条自检命令**全部**给出预期输出。

---

## 1. 你需要的硬件清单

| 项 | 说明 | 检查 |
| --- | --- | --- |
| 树莓派 5 | 主板 + **5V/5A USB-C PD 电源**（电源不足会随机重启/掉线） | ⬜ |
| microSD 卡 | ≥16GB（建议 32GB），Class10/A1 以上 | ⬜ |
| 读卡器 | 烧录系统用 | ⬜ |
| 网线或 WiFi | 与电脑/手机**同一个局域网**（同一个路由器） | ⬜ |
| 传感器若干 | 清单在本项目 `hardware/01-引脚分配表.md` | ⬜ |
| 杜邦线 | 公母/公公/母母都要备 | ⬜ |
| （可选）HDMI 线 + 显示器 | 首次配置用；配好 SSH 后可以不接 | ⬜ |
| （可选）10kΩ 电位器 | MCP3002 备用通道（见 `hardware/`） | ⬜ |

> ⚠️ **TMP36 若是裸 SOT-23 小芯片**，必须焊在转接板上才能插杜邦线——买之前先确认封装。

## 2. 烧录系统（用电脑做）

1. 下载 **Raspberry Pi Imager**：<https://www.raspberrypi.com/software/>
2. 选系统：**Raspberry Pi OS (64-bit) with desktop**（带桌面，方便现场演示）
   > 课程要求"Python 编程"，本项目的树莓派端**只用标准库 + 系统包**，两个版本都能跑；
   > 带桌面版省事（有浏览器可以直接看状态网页）。
3. 点齿轮/高级选项，**提前配好**（省得接显示器）：
   - 主机名：`health-pi`
   - **开启 SSH**：勾选"使用密码认证"
   - 用户名 `pi` + 你记得住的密码
   - **WiFi 名称/密码 + 国家 CN**（不插网线时必填）
   - 时区：`Asia/Shanghai`
4. 烧录 → 插卡 → 上电。**首次开机约 2~3 分钟**，耐心等。

## 3. 连上树莓派

在**电脑**的 PowerShell 里（把 IP 换成你的）：

```powershell
# 方法 A：知道 IP（路由器后台 / 手机热点列表里看）
ssh pi@192.168.1.20

# 方法 B：不知道 IP，用主机名（Windows 10+ 支持 mDNS）
ssh pi@health-pi.local
```

首次连接会问 `yes/no`，输入 `yes`，再输密码。

> 连不上先别怀疑树莓派：确认电脑和树莓派在**同一网段**；Windows 上先 `ping health-pi.local`；
> 还不行就把卡拔下来，在 boot 分区放一个空的 `ssh` 文件（无扩展名）再开机。

## 4. 开 I2C 与 SPI（本项目必须）

```bash
sudo raspi-config
```

依次操作：

| 菜单 | 选择 | 说明 |
| --- | --- | --- |
| `3 Interface Options` | `I5 I2C` | **Enable**（MAX30102 与 LCD 都要用） |
| `3 Interface Options` | `I4 SPI` | **Enable**（MCP3002 要用） |
| `5 Localisation Options` | `L2 Timezone` | `Asia/Shanghai`（**重要**：夜间起夜规则按本地时间判断） |
| `6 Advanced Options` | `A1 Expand Filesystem` | 扩满整张卡（可选） |

改完选 `Finish`，**重启**：

```bash
sudo reboot
```

## 5. 装依赖

本项目树莓派端**核心零第三方依赖**（不装也能跑 mock 模式与全部单测），
但**接真实硬件**需要下面这些：

```bash
sudo apt update
sudo apt install -y python3-smbus i2c-tools \
                    python3-spidev python3-gpiozero python3-lgpio \
                    espeak-ng alsa-utils

# 可选：语音用中文要装中文发音包（不然中文读得怪）
sudo apt install -y espeak-ng-data

# 可选：上云用（OneNET / MQTT）
sudo apt install -y python3-pip
pip3 install --break-system-packages paho-mqtt      # 若提示 externally-managed-environment 就带这个参数
```

各包用途（排查时有用）：

| 包 | 用途 | 缺了会怎样 |
| --- | --- | --- |
| `python3-smbus` + `i2c-tools` | I2C（MAX30102、LCD） | 报 `未安装 smbus2` |
| `python3-spidev` | SPI（MCP3002） | 报 `未安装 spidev` |
| `python3-gpiozero` + `python3-lgpio` | GPIO（按键、PIR、蜂鸣器、LED、DHT11、HC-SR04） | 报 `未安装 gpiozero` |
| `espeak-ng` + `alsa-utils` | 语音播报（TTS + 播放） | 语音自检会 FAIL，其它功能不受影响 |
| `paho-mqtt` | 上云（OneNET / MQTT） | 云端上报不会启动，本地监护不受影响 |

> 📌 **纪律**：这个项目刻意**不在 PC 上要求任何依赖**——所有硬件库都是"用到时才 import，
> 缺了就抛一条带安装命令的错误"。所以你在电脑上跑单测、跑演示不需要装任何东西。

## 7. ★ 上机自检（6 条，全部要过）

**逐条跑，对不上就别往下走**（每条的排查动作写在后面）：

```bash
# ① 系统与 Python 版本
python3 --version && uname -m
```
预期：`Python 3.9` 以上；`aarch64`（64 位）。

```bash
# ② I2C 设备节点存在（开了 I2C 才有）
ls -l /dev/i2c-1
```
预期：出现 `/dev/i2c-1`。没有 ⇒ 回第 4 步重开 I2C 并重启。

```bash
# ③ SPI 设备节点存在
ls -l /dev/spidev0.*
```
预期：`/dev/spidev0.0` 与 `/dev/spidev0.1`。没有 ⇒ 回第 4 步重开 SPI。

```bash
# ④ I2C 总线上都有谁（**还没接传感器时应该是空表，这是正常的**）
i2cdetect -y 1
```
预期：表格里全是 `--`（还没有器件）。接完线后这里要能看到 `0x57` 和 `0x27`。

```bash
# ⑤ 时区正确（夜间起夜规则靠它）
date
```
预期：显示**当前**的本地时间（不是 UTC、不是几小时前的）。不对 ⇒ `sudo raspi-config` 设时区。

```bash
# ⑥ 项目自检（不接硬件，验证代码链路）
cd ~/raspberry-health-monitor/rpi
python3 scripts/validate.py
```
预期：**9 项全 PASS**（末尾打印 `结果：全部 9 项通过`）。
如果这一步就红，那是**代码/环境**问题（还没到硬件问题），把输出贴给我或查 `05-排错手册.md`。

## 8. 可选的省事配置

```bash
# ① 免密 SSH（在电脑上做）：以后不用反复输密码
ssh-keygen -t ed25519            # 一路回车
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh pi@health-pi.local "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

```bash
# ② 固定 IP（推荐，免得路由器换 IP 后手机 App 连不上）
#    用 nmcli（树莓派 OS Bookworm 用 NetworkManager）
nmcli -t -f NAME connection show                 # 看连接名，通常是 "preconfigured" 或 WiFi 名
sudo nmcli connection modify "preconfigured" ipv4.method manual \
     ipv4.addresses 192.168.1.20/24 ipv4.gateway 192.168.1.1 ipv4.dns 192.168.1.1
sudo nmcli connection up "preconfigured"
```
> ⚠️ 把 IP、网关换成**你自己路由器**的网段；改完用新 IP 重新 SSH（旧连接会断）。

```bash
# ③ 关闭屏幕休眠（现场演示时不要让 HDMI 黑屏）
sudo raspi-config     # Display Options → Screen Blanking → Disable
```
