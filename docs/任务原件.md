## H：温湿度测量

**截图**：[`任务截图/课程作业-H温湿度测量.jpg`](任务截图/课程作业-H温湿度测量.jpg)

### 题目原文（逐字抄录）

> **核心任务**：使用树莓派 5 和课程中学习过的温湿度传感器（如 DHT11）周期性读取温度和湿度。
> 程序保存连续采集的数据，并用 Matplotlib 绘制动态曲线；每得到一组新数据，图中的曲线随之刷新。
> 图中应明确标出温度、湿度以及采样顺序或时间，使读者能够观察环境参数随时间的变化趋势。
>
> **示例输出**：运行后出现动态曲线窗口，温度曲线和湿度曲线随着新数据不断向前延伸。
> 例如最新一次数据为"温度: 25.0 ℃，湿度: 58%"，下一次采样后图中增加一个新的数据点。

> 截图下方还有后续条目（形如 `I：红外传感…`），用户告知：**后面的任务不让做**（只做 H）。

## 逐条要求 → 我们的实现（对照表）

| # | 题目要求 | 我们的实现 | 状态 |
| --- | --- | --- | --- |
| 1 | 使用**树莓派 5** | Raspberry Pi 5 Model B Rev 1.1（真机已验证） | ✅ |
| 2 | 课程学过的**温湿度传感器（如 DHT11）** | DHT11 驱动（`sensors/dht11.py`），GPIO4=物理脚 7 | ⚠️ 驱动已实现（含自实现单总线），**器件侧仍不应答，待排查** |
| 3 | **周期性**读取温度和湿度 | `core/collector.py` 按各设备自己的周期轮询；DHT11 设为 3 秒（硬件要求 ≥2 秒） | ✅ |
| 4 | 程序**保存连续采集的数据** | 每次采集写入 SQLite（`data/history.db`）+ `GET /api/v1/history` 查询 | ✅ |
| 5 | 用 **Matplotlib 绘制动态曲线** | `rpi/scripts/live_plot.py`（Tkinter + `FuncAnimation`） | ✅ 脚本就绪，真机出图已实测（mock 数据） |
| 6 | 每得到一组新数据，**曲线随之刷新** | 每个采样周期追加一个点，双曲线同步右移（滚动窗口） | ✅ |
| 7 | 图中明确标出**温度、湿度**以及**采样顺序或时间** | 左轴 `温度 (℃)`（红）+ 右轴 `湿度 (%)`（蓝）+ 图例；横轴可切**时间(秒)**或**采样序号** | ✅ |
| 8 | **示例输出**：最新一次"温度: 25.0 ℃，湿度: 58%" | 窗口标题实时显示 `最新一次读数　温度: 25.0 ℃　湿度: 58 %`；终端同步打印 | ✅ |
| 9 | 观察随时间变化的**趋势** | 滚动窗口（默认 120 点）+ 底部状态行显示范围与累计样本数 | ✅ |

**结论**：要求 1、3–9 已满足且高于题目要求；**唯一未完成的是第 2 条的真机读数**——
DHT11 模块目前对启动信号无应答（驱动侧已修好并用合成时序测试验证），
排查步骤见 [`../10-树莓派接入与上云实联调.md`](../10-树莓派接入与上云实联调.md) 第 6 节 ①。

## 怎么跑（答辩/验收用）

```bash
cd ~/raspberry-health-monitor/rpi

# ① 装依赖（树莓派上，只需一次）
sudo apt install -y python3-tk python3-matplotlib fonts-noto-cjk

# ② 直接读 DHT11 画动态曲线（最短链路）
python3 scripts/live_plot.py

# ③ 或复用本项目已落库的连续数据
python3 -m health_monitor serve --real &
python3 scripts/live_plot.py --source api --interval 3

# 常用参数
python3 scripts/live_plot.py --xaxis index        # 横轴改成"采样序号"
python3 scripts/live_plot.py --window 60          # 只保留最近 60 个点
python3 scripts/live_plot.py --save curves.png    # 每帧导出图片（报告插图）
python3 scripts/live_plot.py --mock --headless --duration 30 --save curve.png   # 无显示器也能出图
```
