## 1. 铁律（连上之后我依然遵守）

1. **不看 GUI、不动鼠标键盘**（项目铁律：不许劫持用户鼠标；也没法"看屏幕"）。
2. **只读优先**：看日志、跑体检、抓接口；改代码走 `git`/`scp`，每步都告诉你动了什么。
3. **不改你树莓派上的系统配置**（时区/网络/自启），除非你明确说"改吧"。
4. **不碰隐私**：`/api/v1/*` 里的数据是本机传感器数值，不外传；密钥与 token 不打印内容。
5. **随时可收回**：删掉本机私钥 + 树莓派 `authorized_keys` 里那一行，我就再也进不去。

## 2. 晚上照这个顺序做

### 2.1 电脑开热点（2 分钟）

1. `Win + I` → **网络和 Internet → 移动热点**
2. 「**共享以下连接**」选 **宽带连接 2**（有 Internet 的那条）
3. 「**通过以下方式共享**」选 **Wi-Fi**
4. 点「**编辑**」设置：
   - 网络名称（SSID）：`pi-debug`
   - 密码：**≥12 位强密码**（例如 `PiDebug-2026-raspi`）
   - **网络频段**：优先 **5 GHz**；若树莓派连不上就改 **2.4 GHz**（兼容性最好）
   - **网络类型**：选 **WPA2-Personal**（⚠️ 避免只开 WPA3：树莓派 OS 的 `wpa_supplicant` 对纯 WPA3 支持不稳）
5. 打开「移动热点」开关 → 状态应变成"已连接设备：0"

**验证（电脑侧）**：热点网卡会出现，通常网关是 `192.168.137.1`：
```powershell
Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -like '192.168.137.*' } |
  Select-Object IPAddress, InterfaceAlias
```
> 若网段不是 `192.168.137.x`，**记下这个网关 IP**（例如 `192.168.137.1`），后面要用。

### 2.2 树莓派连热点（1 分钟）

树莓派接显示器键盘，点右上角 WiFi 图标 → 选 `pi-debug` → 输密码。
或命令行（树莓派 5 / Bookworm）：

```bash
nmcli device wifi list                       # 确认能看到 pi-debug
sudo nmcli device wifi connect "pi-debug" password "你的密码"
ip -br addr show wlan0                       # 看分到的 IP（一般 192.168.137.x）
```

**同时确认 SSH 开着**：

```bash
sudo systemctl enable --now ssh
systemctl is-active ssh      # 应输出 active
```

### 2.3 给树莓派一个固定 IP（推荐，1 分钟）

热点是 DHCP，IP 可能变。让树莓派固定一个（例如 `192.168.137.3`）：

```bash
# 查看连接名（通常就是 pi-debug）
nmcli -t -f NAME connection show
sudo nmcli connection modify "pi-debug" ipv4.method manual ipv4.addresses 192.168.137.3/24
sudo nmcli connection up "pi-debug"
ip -br addr show wlan0        # 应看到 192.168.137.3/24
```

> 不想固定也行：那就让我用 §2.5 的办法**从 ARP 表里找出树莓派的 IP**（热点网段小，很好找）。

### 2.4 我这边把别名切到热点网段（10 秒）

我改一行就行（`C:\Users\micak\.ssh\config` 里 `Host pi-health` 的 `HostName`）：

- 固定 IP 方案 → `HostName 192.168.137.3`
- 或让我先用 §2.5 找出真实 IP 再填

### 2.5 找不到树莓派 IP 时（热点网段很小，好找）

```powershell
# ① 看邻居表（树莓派连上热点后会出现在这里，带 MAC）
Get-NetNeighbor -AddressFamily IPv4 | Where-Object { $_.IPAddress -like '192.168.137.*' -and $_.State -ne 'Unreachable' } |
  Select-Object IPAddress, LinkLayerAddress, State

# ② 试 mDNS 主机名
Resolve-DnsName health-pi.local -ea SilentlyContinue
Resolve-DnsName raspberrypi.local -ea SilentlyContinue

# ③ 拿候选 IP 逐个试 22 端口
1..20 | ForEach-Object { $ip = "192.168.137.$_"; if (Test-NetConnection $ip -Port 22 -InformationLevel Quiet -WarningAction SilentlyContinue) { "SSH 在此：$ip" } }
```

### 2.6 装公钥（免密登录，1 分钟）

电脑上执行（第一次要输树莓派密码；把 IP 换成 §2.4/2.5 得到的那个）：

```powershell
type $env:USERPROFILE\.ssh\id_ed25519_pi_health.pub | ssh pi@192.168.137.3 "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"
```

**公钥内容**（如需你在树莓派上手动追加）：

```
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAINLiPaoAimbW9FKJY1/YB6P5V6LZBZo3XYWb/oWbDwSW dsh-agent@pc-for-raspberry-health-monitor
```

**验证免密**：
```powershell
ssh -o BatchMode=yes pi-health "hostname; uname -m"
```
输出主机名与 `aarch64` ⇒ ✅ 成功。

## 3. 连上后我会跑的只读诊断（你也可以自己先试）

```bash
# 1) 身份与环境
ssh pi-health "hostname; cat /proc/device-tree/model; python3 --version; date"
# 2) 内核接口是否就绪
ssh pi-health "ls -l /dev/i2c-1 /dev/spidev0.0; ls /dev/gpiochip*"
# 3) I2C 总线上都有谁（关键判据）
ssh pi-health "i2cdetect -y 1"
# 4) 代码与依赖
ssh pi-health "cd ~/raspberry-health-monitor/rpi && git log --oneline -1 && python3 scripts/validate.py"
# 5) 逐器件真机体检（失败会给排查线索）
ssh pi-health "cd ~/raspberry-health-monitor/rpi && sudo python3 scripts/hardware_test.py --skip-output --json /tmp/hw.json"
```

**我会给你一份结论**，形如：

| 器件 | 现象 | 归类 | 下一步 |
| --- | --- | --- | --- |
| MAX30102 | I2C 扫到 0x57，但心率恒 `--` | 用法/环境 | 手指盖严；等 10 秒；遮强光 |
| TMP36 | raw 恒 1023 | **接线** | VOUT 或供电接错（5V/CH0/共地） |
| LCD | 未扫到地址 | **接线** | SDA/SCL 反了或 VCC 电压不对 |
| DHT11 | 一直返回缓存值 | 配置 | `read_interval_s` 提到 3 秒 |

能——热点是**带 Internet 共享**的（你选了共享"宽带连接 2"）：


若不通，检查「移动热点」页面里"共享以下连接"是否选对了那条有 Internet 的连接。

## 6. 兜底方案：网线直连电脑（热点不稳时用）

1. **电脑侧**（把"以太网"换成真网口名；`以太网`=Realtek 千兆口）：
   ```powershell
   New-NetIPAddress -InterfaceAlias "以太网" -IPAddress 192.168.50.2 -PrefixLength 24
   ```
2. **树莓派侧**：
   ```bash
   sudo nmcli connection modify "Wired connection 1" ipv4.method manual ipv4.addresses 192.168.50.3/24
   sudo nmcli connection up "Wired connection 1"
   ```
3. **我这边**：`C:\Users\micak\.ssh\config` 里 `pi-health` 的 `HostName` 改回 `192.168.50.3`
4. 用完还原电脑网卡：
   ```powershell
   Get-NetIPAddress -InterfaceAlias "以太网" -AddressFamily IPv4 | Remove-NetIPAddress -Confirm:$false
   Set-NetIPInterface -InterfaceAlias "以太网" -Dhcp Enabled
   ```

> 网线直连时**电脑的那个网口没有 Internet**（不影响 WiFi/宽带上网，但别把默认路由弄乱）。

## 7. 连不上时的排错

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 树莓派搜不到 `pi-debug` | 频段不兼容（6GHz）或驱动问题 | 热点频段改 **2.4 GHz**；确认热点开关是"开" |
| 树莓派输密码连不上 | 热点开了 WPA3 或密码含特殊字符 | 改 **WPA2-Personal**；密码用字母数字 |
| 连上了但 `ssh` 超时 | 树莓派 IP 猜错 / SSH 没开 | §2.5 找 IP；树莓派上 `systemctl is-active ssh` |
| `Permission denied (publickey)` | 公钥没装上 / 用户名不对 | 重做 §2.6；确认用户是 `pi` |
| `REMOTE HOST IDENTIFICATION HAS CHANGED` | 重烧过系统（主机密钥变了） | `ssh-keygen -R <IP>` 后重连 |
| 热点开不了 / 灰掉 | 无线网卡被禁用、或驱动异常 | 设备管理器看 MT7925 是否正常；重启 WLAN 服务 |
| 树莓派连上但上不了网 | 共享的连接选错 | 移动热点里"共享以下连接"选有 Internet 的那条 |

## 8. 安全与收回权限

- 私钥只在本机 `C:\Users\micak\.ssh\id_ed25519_pi_health`，**不要**拷给别人、不要提交到仓库。
- 树莓派侧授权记录在 `~/.ssh/authorized_keys`，注释是 `dsh-agent@pc-for-raspberry-health-monitor`，一眼能认出来。
- **收回**：
  ```bash
  # 树莓派上删掉那一行（保留你自己的其他公钥）
  sed -i '/dsh-agent@pc-for-raspberry-health-monitor/d' ~/.ssh/authorized_keys
  ```
  ```powershell
  # 本机删私钥（可选）
  Remove-Item $env:USERPROFILE\.ssh\id_ed25519_pi_health* -Force
  ```
- **用完关热点**（设置里关掉开关）；不要把 22 端口映射到公网。
