## 阅读路线（按角色）

**新同学第一天上手**：
`README.md`（跑通 30 秒上手）→ `docs/03-器件任务书.md`（认领器件）→
`docs/04-驱动开发规范与贡献指南.md`（照范本写驱动）→ `docs/02-接口规格说明书.md`（查契约细节）

**安卓同学**：`docs/05-安卓通信协议.md` → `docs/06-安卓开发指南.md` → `README.md` §4

**组长**：`docs/01-项目管理.md` → `contrib/团队分工与提交规范.md` → `docs/03-器件任务书.md` §7（进度表）

**改接口的人**：`docs/02-接口规格说明书.md` → `docs/CHANGELOG-接口.md` → `docs/05-安卓通信协议.md`（若影响手机端）

## 维护约定

- **文档与代码必须同步**：改了 `rpi/health_monitor/hal/` ⇒ 更新 `02` 与 `CHANGELOG-接口`；
  改了 `rpi/health_monitor/net/web.py` ⇒ 更新 `05`。
- 文档里的**引脚号**必须与 `config/devices.json` 一致（`scripts/validate.py` 会检查撞脚，
  但"文档抄错引脚"只有人眼能抓——所以引脚一律由 `hal.pins.describe_pin()` 生成）。
- 文档里的**日期**必须是从命令读到的真实日期，不凭记忆写。
- 文档**不同步到 `D:\code\github_repository\` 的只有两类**：`DEVELOPMENT.md`、`ERROR.md`（开发副本专用）。
  其余文档全部入库，随源码一起提交。
