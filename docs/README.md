> - **操作手册**（本目录根下的 `00`–`11`）：**照着做**的步骤（命令、判据、排错），给动手的人；

## 维护约定

- **文档与代码必须同步**：改 `rpi/health_monitor/hal/` ⇒ 更新 `手册/02` 与 `CHANGELOG-接口`；
  改 `rpi/health_monitor/net/web.py` ⇒ 更新 `手册/05`；
  改 `rpi/health_monitor/net/onenet.py` ⇒ 更新 `04-OneNET云端接入.md` 与 `11-OneNET参考.md`。
- **引脚号**必须与 `config/devices.json` 一致（`scripts/validate.py` 会查撞脚；
  引脚一律由 `hal.pins.describe_pin()` 生成，不许手写）。
- **日期**必须是从命令读到的真实日期，不凭记忆写。
- 文档链接是否悬空、索引是否少条目、报警码是否三方一致 —— 都由
  `python3 scripts/check_docs.py` 机器检查（已接入 `validate.py` 与 CI）。
