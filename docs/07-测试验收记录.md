# 07 · 测试验收记录表（**填完就是报告里的那张表**）

> 用法：每完成一项就填一行。**"结果"列的三档含义**：
> `✅ 实测通过`（真机上亲眼看到） / `⚠️ 部分`（有附加说明） / `⬜ 未实测`（还没做）
>
> ⚠️ **最重要的纪律**：**"单测通过" ≠ "真机通过"**。
> 单测证明代码逻辑对；真机才能证明**接线、地址、时序**对。两列必须分开填，
> 报告里也**如实**写清哪些是模拟验证、哪些是实物验证。

## 2. 真机硬件验收（**接上器件后逐行填**）

统一用项目自带的验收脚本跑，它会把结果打印出来，你照着抄进表：

```bash
cd ~/raspberry-health-monitor/rpi
sudo python3 scripts/hardware_test.py --json ~/hardware-report.json      # 全量

# 阶梯式推进（一次只加一个器件，见 docs/14）：先只验这一级新加的器件，
# 前置检查（I2C/SPI/依赖）会自动跟着收窄，不会因为"还没接的器件"满屏报错
python3 scripts/hardware_test.py --list                    # 查设备名
sudo python3 scripts/hardware_test.py --only ambient       # 例如只验 DHT11
```
