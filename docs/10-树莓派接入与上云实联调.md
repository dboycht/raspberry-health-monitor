## 4. 期间踩的坑（都修了，且都补了防御）

| # | 现象 | 根因 | 修法 |
| --- | --- | --- | --- |
| 1 | 公钥明明装上，仍 `Permission denied (publickey)` | Windows 下 `.pub` 是 **CRLF**，`\r` 写进 `authorized_keys` 后 sshd 解析失败 | 安装前**规范化**（去 CR/BOM）并**内联公钥**安装，不走管道 |
| 2 | `ssh-copy-id` 报 `WinError 193 不是有效的 Win32 应用程序` | Windows 上命中的是 **Git 自带的 Bash 脚本**，不能直接执行 | 只认 `.exe/.cmd/.bat`，否则退回等效命令 |
| 3 | 树莓派上"文档一致性"检查失败、本地却通过 | 检查器的**注入自测**硬编码 `docs/README.md` 当"真实文件" —— 只在"仓库根 == 项目根"时成立 | 自测**临时造文件**来验证"不误报" |
| 4 | 树莓派上缺 `android/.../data/*.kt`，文档检查报悬空 | 打包时用了 `tar --exclude=data`，GNU tar 的排除模式**无锚定概念**，把任意层级的 `data` 目录都吃掉了（与项目历史上 `.gitignore` 的坑同类） | 改用**白名单暂存目录**打包 |
| 5 | `.gitignore` 里的 `/config/devices.local.json` **没生效** | 加了前导斜杠 → 锚定到仓库根，而文件其实在 `rpi/config/` 下 | 改成不带斜杠的 `devices.local.json`，并用 `git check-ignore` 实测 |
| 6 | 数据点发不出去、`published=0`、毫无提示 | 探针用了**自造的键**（`probe_temp`），不在 `stream_map` 里 → 映射后没有任何字段 → 静默 return | ① 探针改用真实键；② 代码**必须留痕**：累加 `skipped_empty` + 记 warning |
| 7 | 发布成功但**收不到平台回执** | 配置里 `topic_template` **少了 `$sys/` 前缀** → 订阅到错误主题，丢掉了"是否被接收"的唯一硬证据 | 代码**新增校验**：不是以 `$sys/` 开头就直接报错并说明后果 |
| 8 | 同一份测试：开发机绿、树莓派红 | 新测试依赖"这台机器上有没有 `devices.local.json`" | `load_config(..., use_local=False)` 显式隔离环境；测试自己造临时覆盖文件 |

> 这些经验已写入项目 `ERROR.md`（详录）。

## 7. 软件侧本轮改动（2026-09-24）

| 改动 | 说明 |
| --- | --- |

## 11. 新增：基础版 `basic/`（课程作业 H 的最小可用版，2026-09-25）

用户要求"先做一个 basic 版本、单独一个文件夹，把最基本的大作业完成"，
于是新增 [`../basic/`](../basic/README.md)：**不 import 主项目**，整个文件夹拷走就能交。

```bash
# 树莓派上（三条命令）
cd basic
sudo apt install -y python3-matplotlib python3-tk python3-lgpio   # 只需一次（中文字体已随包，见 basic/fonts/）
python3 tools/selfcheck.py     # ① 10 项自检
python3 run.py                 # ② 读 DHT11（GPIO4 = 物理脚 7）+ 动态曲线窗口
python3 run.py --no-plot       # ③ 只采集与存档（CSV）
cd hw && python3 run.py        # ④ 单文件作业版（一个文件跑完题设，交作业推荐）

# 电脑上（没有硬件也能验证）
python3 run.py --mock          # 合成数据看曲线
python3 run.py --replay        # 回放 basic/data/sample_demo.csv
```

- **接线与主项目 DHT11 完全一致**：VCC→3.3V（脚 1/17）、DATA→GPIO4（脚 7）、GND→任意 GND；
  四针裸传感器要接 4.7k~10k 上拉；
- 与主项目的差别：数据存 **CSV**（每行即时 fsync）而不是 SQLite；只有温湿度一条链路；
- **基础版自带一份 DHT11 读取**（`basic/dht11read.py`，lgpio 边沿时间戳 / gpiozero / mock 三后端），
  与主项目驱动是**两份独立实现**——真机验收时两边都要各跑一次并分别记录；
- **真机结果**（2026-09-25 夜）：基础版连续采集 **111 个样本全成功**（23.8~24.2 ℃ / 57~58 %），
  曲线图与原始数据在 `../basic/evidence/`；
- 逐条对照题目 + 验收结果见 [`../basic/验收说明.md`](../basic/验收说明.md)
  与交付说明 [`../basic/交接文档.md`](../basic/交接文档.md)；
- 提交前检查已并入：`cd rpi && python scripts/validate.py` 的**第 10 项**会跑基础版自检 + 125 项单测。
