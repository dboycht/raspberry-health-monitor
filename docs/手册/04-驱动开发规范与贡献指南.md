## 3. 写一个输入型驱动（传感器）—— 完整骨架

```python
"""一句话说明这是什么器件。

接线
----
=========  ===================  =========================
器件引脚    树莓派 40-pin        说明
=========  ===================  =========================
VCC        脚 1（3.3V）          供电
GND        脚 6                  共地
SDA        脚 3（GPIO2）         I2C 数据
SCL        脚 5（GPIO3）         I2C 时钟
=========  ===================  =========================

设计要点
--------
1. 纯算法抽成独立函数/类，可脱离硬件单测；
2. mock 模式绝不碰硬件；
3. 失败留痕，不静默。

负责人：<姓名/学号>
"""

from __future__ import annotations

import time
from typing import Any, Dict, Optional

from ..hal.device import Device
from ..hal.exceptions import DataInvalidError, DeviceInitError, DeviceIOError
from ..hal.models import DeviceKind, PrecisionTempSample, now_ts

#: I2C 地址（写清它，答辩会被问）
ADDRESS = 0x57


class MySensor(Device):
    """器件说明（中文）。"""

    KIND = DeviceKind.PRECISION
    NAME = "my_sensor"          # 必须与 registry.MANIFEST 的键一致

    def __init__(
        self,
        bus: Any = None,
        address: int = ADDRESS,
        mock: bool = False,
        name: str = "",
    ) -> None:
        super().__init__(bus=bus, mock=mock, name=name)
        self.address = int(address)
        self._io: Any = None

    # -- 生命周期 -------------------------------------------------------

    def open(self) -> None:
        if self._opened:
            return
        if self.mock:
            self._opened = True          # mock：什么都不做
            return
        try:
            from smbus2 import SMBus      # 函数内延迟导入（真实树莓派才有）
        except ImportError as exc:
            raise DeviceInitError(
                f"未安装 smbus2：树莓派上执行 `sudo apt install -y python3-smbus`（{exc}）"
            ) from exc
        try:
            self._io = SMBus(1)
        except OSError as exc:
            raise DeviceInitError(
                f"I2C 打开失败：{exc}。请先 `sudo raspi-config` 开启 I2C，"
                "并用 `i2cdetect -y 1` 确认器件在线"
            ) from exc
        self._opened = True

    def read(self) -> PrecisionTempSample:
        self._require_open()
        try:
            raw = self._read_raw()
        except DeviceIOError:
            raise
        except Exception as exc:                     # 其它异常统一翻译
            self._note_fault(exc)
            raise DeviceIOError(f"读取 {self.name} 失败：{exc}") from exc
        if not self._valid(raw):
            self._note_fault(DataInvalidError(f"读数 {raw} 超出量程"))
            return PrecisionTempSample(
                ts=now_ts(), device=self.name, ok=False,
                error=f"读数 {raw} 超出量程",
            )
        self._note_ok()
        return PrecisionTempSample(ts=now_ts(), device=self.name, raw_adc=raw, voltage_v=raw / 1023 * 3.3)

    def close(self) -> None:
        if self._io is not None:
            try:
                self._io.close()
            except Exception:
                pass
            self._io = None
        self._opened = False

    # -- 纯逻辑（可单测，不碰硬件） -------------------------------------

    @staticmethod
    def _valid(raw: int) -> bool:
        return 0 <= raw <= 1023

    def _read_raw(self) -> int:
        if self.mock:
            return 512
        return int(self._io.read_i2c_block_data(self.address, 0x00, 2)[0])

    # -- 文档与自检 -----------------------------------------------------

    def describe(self) -> Dict[str, Any]:
        return {
            "name": self.name, "kind": self.KIND.value, "mock": self.mock,
            "bus": f"I2C-1 地址 0x{self.address:02X}",
            "pins": {"sda": "GPIO2 / 物理脚 3", "scl": "GPIO3 / 物理脚 5",
                     "vcc": "3.3V / 物理脚 1", "gnd": "GND / 物理脚 6"},
            "notes": "…",
        }
```

## 4. 写一个输出型驱动（显示/声音/灯）—— 骨架

```python
from ..hal.device import OutputDevice
from ..hal.exceptions import AlarmDispatchError, UnsupportedError
from ..hal.models import BeepCommand, DeviceKind


class MyOutput(OutputDevice):
    KIND = DeviceKind.AUDIO
    NAME = "my_output"

    def open(self) -> None:
        if self.mock:
            self._opened = True
            return
        # …真实初始化…

    def send(self, command) -> None:
        if not isinstance(command, BeepCommand):
            # ⚠️ 不认识的指令必须**明确报错**，不许静默忽略
            raise UnsupportedError(f"{self.name} 不接受 {type(command).__name__}")
        if self.mock:
            self.history.append(command)      # mock：只记录，不真的发声
            return
        try:
            self._do_beep(command)
        except Exception as exc:
            raise AlarmDispatchError(f"{self.name} 执行失败：{exc}") from exc

    def close(self) -> None:
        self._opened = False
```

**输出型驱动的三条附加纪律**（都在接口规格里，这里再强调一次）：
1. **防吵人**：蜂鸣器单次 ≤10 秒；音箱同句 10 秒内不重复；
2. **外部命令必须可替换**：`runner: Callable = subprocess.run` 作为构造参数，
   单测注入假 runner 并断言"执行了哪些命令"，**绝不真的出声**；
3. **LCD 只认 ASCII**：非 ASCII 要安全降级。

## 5. 单测怎么写（本项目的"可执行判据"）

```python
import unittest
from health_monitor.hal import DeviceNotReady, MockBus
from health_monitor.sensors.my_sensor import MySensor


class TestMySensor(unittest.TestCase):
    def test_未open就read必须报错(self):
        with self.assertRaises(DeviceNotReady):
            MySensor(mock=True).read()

    def test_mock模式不碰硬件(self):
        with MySensor(mock=True) as d:
            self.assertIsNone(d._io)                  # 没有创建真实总线对象
            self.assertTrue(d.read().ok)

    def test_总线故障被翻译成DeviceIOError并留痕(self):
        bus = MockBus().fail_next()
        d = MySensor(bus=bus, mock=True)
        d.open()
        with self.assertRaises(Exception):
            d.read()
        self.assertGreaterEqual(d.status()["fault_count"], 1)
        self.assertIsNotNone(d.status()["last_error"])   # **不许静默失败**

    def test_close幂等(self):
        d = MySensor(mock=True)
        d.open(); d.close(); d.close()                # 不应抛异常
```

**写断言的三条纪律**（都来自本项目实际踩坑）：
1. **不许恒真断言**：`assertTrue(x or True)`、`assertGreaterEqual(n, 0)` 这类等于没测；
2. **判据要可执行、带数值**：`assertLess(abs(hr - 60), 6)` 好过 `assertIsNotNone(hr)`；
3. **负例也要测**：读失败、超量程、坏数据、超时——**阴性结果比阳性更需要验证**。

## 6. 调试手法（没有硬件时）

| 场景 | 做法 |
| --- | --- |
| 想看驱动到底发了哪些字节 | `bus.operations("i2c_write")` / `bus.operations("spi_xfer")` |
| 想造总线故障 | `bus.fail_next()` / `bus.fail_times(3)` |
| 想造坏数据 | 让钩子返回超量程值（如 `raw=1023`） |
| 想看真实设备是否在线 | 树莓派上 `i2cdetect -y 1`；SPI：`ls /dev/spidev0.*` |
| 想看某个驱动单独跑起来什么样 | `python -m health_monitor selfcheck --mock`（或 `--real`） |
| 想验证"我的器件在整机里也正常" | 在 `config/devices.json` 里把它的 `enabled` 设为 `true` 后 `serve --mock` |

## 7. 依赖纪律（**先问再加**）

- **运行时只用**：Python 标准库 + 树莓派系统包（`smbus2` / `spidev` / `gpiozero` / `lgpio`）+ 系统命令（`espeak-ng` / `aplay`）。
- **导入方式**：一律**函数内延迟导入 + `try/except ImportError`**，
  并抛出带安装命令的 `DeviceInitError`。原因：PC 上没有这些包，顶层 import 会让**整个服务起不来**。
- 想加新依赖（pip 包）→ **先在群里问**，说明"为什么标准库/系统包做不到"，
  并同步更新 `rpi/requirements-optional.txt` 与 README。

## 8. 代码风格

- 中文注释与文档字符串（这是教学项目）；变量名用英文。
- 类型标注齐全（`def read(self) -> PrecisionTempSample:`）。
- 不用 `print` 做日志，用 `logging`（`_LOG = logging.getLogger(__name__)`）。
- 一文件一器件；**驱动之间不要互相 import**（需要协同就放到 `core/`）。

## 11. 常见问题（FAQ）

**Q：我的驱动 mock 模式下要不要真的读总线？**
A：不要。mock 就是"没有硬件"，用固定值或 `MockBus` 钩子产生**物理合理**的数据，
并且要能让演示/剧本改值（提供 `inject_*` 方法，仅 mock 可用，真实模式抛 `UnsupportedError`）。

**Q：读到坏数据应该 `return ok=False` 还是抛异常？**
A：**瞬时**问题（总线抖动、超时）→ 抛 `DeviceIOError`/`DeviceTimeout`（上层会重试）；
**数据本身不可信**（超量程）→ 返回 `ok=False` 的样本或抛 `DataInvalidError`（重试无用）。
两种都要 `_note_fault()` 留痕。

**Q：我的传感器 30 秒才需要读一次，可以吗？**
A：可以，在 `config/devices.json` 里设 `read_interval_s`（DHT11 必须 ≥2 秒）。
采集器会按各设备自己的周期调度，不会统一节拍。

**Q：我改了 `models.py` 加了个字段，别人的测试红了怎么办？**
A：说明你改了契约。正确流程：① 先改文档；② 通知大家；③ 字段要有默认值（dataclass 默认值保证向后兼容）。
**新增字段是兼容的，改字段含义/删字段是破坏性的。**

**Q：为什么我的驱动在 `serve` 里没被用上？**
A：检查 `config/devices.json` 里 `enabled` 是否为 `true`；再跑 `python -m health_monitor status --mock` 看"装配"情况。
若装配失败，`status` 里会有 `errors` 字段说明原因。
